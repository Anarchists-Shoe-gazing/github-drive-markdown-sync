개인정보처리방침

적용일 및 문서 버전: 2026-11-03

이 방침은 Anarchists-Shoe-gazing이 운영하는 GitHub Markdown Sync에 적용됩니다. 앱은 운영자가 선택한 GitHub 저장소의 Markdown 파일을 자신의 Google Drive로 복사하는 개인·운영자용 자동화입니다. 공개 회원가입이나 제3자 계정 연결 서비스는 제공하지 않습니다.

접근하는 정보와 사용 목적

  • GitHub: 선택한 저장소의 .md 파일 내용과 경로, 변경·커밋 정보 등 복사에 필요한 정보를 읽습니다.
  • Google Drive: 연결 계정 확인에 필요한 계정 정보와 대상 폴더·파일의 이름, ID, 경로, 수정 시각, 크기, 해시 등 메타데이터를 확인합니다. 대상 파일을 생성하거나 업데이트하는 데 Markdown 내용을 사용합니다.
  • 인증정보: OAuth 클라이언트 정보와 액세스·리프레시 토큰을 Google Drive 연결 및 갱신에 사용합니다.
  • 실행 기록: 처리 경로, 상태, 해시 등 운영·검증용 메타데이터를 기록합니다. 파일 본문이나 인증 토큰을 로그에 출력하지 않도록 구성합니다.
OAuth 권한은 Drive 전체에 적용됩니다.

사용 범위는 https://www.googleapis.com/auth/drive입니다. 이 권한은 Drive 전체의 파일 조회·생성·수정·삭제를 허용합니다. 앱은 지정된 기존 폴더 안에서 복사·업데이트하도록 설정되지만, root_folder_id는 작업 위치 설정일 뿐 OAuth 권한을 폴더 단위로 제한하지 않습니다. 앱의 복사 작업은 원본에서 삭제된 파일을 Drive에서 자동 삭제하지 않습니다.

데이터가 이동하고 처리되는 곳

선택한 GitHub 저장소 → 운영자의 로컬 Mac mini 또는 GitHub가 호스팅하는 Actions 실행 환경 → 운영자가 지정한 Google Drive 폴더 순서로 처리됩니다. 이 과정에 필요한 데이터는 GitHub와 Google의 서비스에서 처리되며 각 제공자의 정책이 적용됩니다.

앱은 데이터를 판매하거나 광고 타기팅 또는 AI 모델 학습에 사용하지 않습니다. 별도 사용자 데이터 서버를 운영하지 않으며, 기능 수행과 운영자에게 필요한 점검 외의 목적으로 파일 내용을 이용하지 않습니다.

인증정보와 보관 기간

로컬 인증 설정은 소유자만 접근하도록 제한한 디렉터리(권한 700)와 파일(권한 600)에 보관합니다. 이는 파일 접근 권한 제한이며 로컬 암호화를 뜻하지 않습니다. Actions에서 필요한 인증정보는 GitHub의 암호화된 Secrets에 저장하며 소스 코드에 넣지 않습니다.

Drive에 복사한 파일은 소유자가 삭제할 때까지 해당 Drive에 남습니다. 로컬 작업 파일·설정과 운영 기록은 운영자가 관리하고 필요가 없어지면 삭제합니다. GitHub Actions의 실행 기록은 GitHub의 보관 설정을 따릅니다. OAuth 토큰의 저장된 값은 관련 로컬 설정·GitHub Secrets에서 삭제할 때까지 남을 수 있습니다. Google 권한 해제는 앱의 접근을 차단하지만 저장된 설정값을 자동으로 지우지는 않습니다.

자동화 중단, 권한 해제 및 삭제

  1. 예약·이벤트에 따른 업로드를 막으려면 해당 저장소의 GDRIVE_SYNC_ENABLED를 false로 설정합니다. 별도로 실행 중인 로컬 작업도 중단합니다.
  2. Google 계정의 서드 파티 연결 관리에서 이 앱을 선택하고 Google 계정 접근 권한을 해제할 수 있습니다. Google의 연결 해제 안내도 참고할 수 있습니다.
  3. 이 연결을 더 사용하지 않으면 관련 로컬 인증 설정과 GitHub Secrets를 삭제합니다. 설정 삭제와 Google 권한 해제는 각각 수행해야 합니다.
  4. 이미 복사된 파일은 연결 해제 후에도 Drive에 남습니다. 소유자가 자신의 Drive에서 직접 보관·삭제합니다.

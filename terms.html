문서 버전: 2026-11-03

이 문서는 Anarchists-Shoe-gazing이 운영하는 GitHub Markdown Sync의 사용 범위와 동작을 설명합니다. 앱은 개인·운영자용 자동화이며 공개 회원가입, 유료 구독 또는 제3자 계정을 연결해 주는 서비스를 제공하지 않습니다.

연결할 수 있는 대상

운영자가 소유하거나 필요한 접근·복사 권한을 가진 GitHub 저장소와 Google Drive 계정·폴더만 연결합니다. 저장소의 공개 여부와 관계없이 파일을 다른 저장 위치로 복사할 권한이 있는지 먼저 확인합니다.

복사와 업데이트의 동작

  • 선택한 저장소의 .md 파일을 지정한 기존 Drive 폴더로 복사하고 하위 폴더 구조를 유지합니다.
  • 동일한 대상 경로의 파일은 업데이트할 수 있습니다. 중요한 문서는 사본과 변경 이력을 직접 관리합니다.
  • 원본에서 삭제된 파일을 Drive에서 자동으로 삭제하지 않습니다. 복사 결과의 보관·정리는 파일 소유자가 관리합니다.
  • 자동 실행은 기본적으로 비활성입니다. 실행 전 대상 저장소·폴더를 확인하고 dry-run 결과를 검토합니다.

권한, 실행 환경 및 비용

Google 연결은 Drive 전체 권한인 https://www.googleapis.com/auth/drive를 사용합니다. 지정 폴더 설정이 OAuth 권한 자체를 좁히지는 않습니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

실행에는 운영자의 로컬 Mac mini 또는 GitHub Actions와 Google Drive를 사용합니다. GitHub와 Google의 계정 상태, 사용 한도 및 요금 설정에 따라 실행이 제한되거나 제공자 사용료가 발생할 수 있습니다. 이 앱을 사용한다는 이유로 요금제나 지출 한도를 자동 변경하지 않습니다. 비용이 발생할 수 있는 실행은 운영자가 별도로 확인합니다.

중단과 연결 해제

GitHub 저장소의 GDRIVE_SYNC_ENABLED=false로 이벤트·예약에 따른 업로드를 차단하고 별도 로컬 실행도 중단합니다. Google 계정의 서드 파티 연결 관리에서 권한을 해제한 뒤 필요 없는 로컬 인증 설정과 GitHub Secrets를 삭제할 수 있습니다. 이미 복사된 Drive 파일은 그대로 남으며 소유자가 관리합니다.

지원과 문서 변경

운영 문의와 오류 보고는 프로젝트의 GitHub Issues를 이용합니다. 공개 문의에는 인증정보나 민감한 파일 내용을 넣지 않습니다. 기능이나 데이터 처리 방식이 달라지면 관련 문서의 버전을 갱신합니다.

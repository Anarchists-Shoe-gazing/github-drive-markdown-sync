GitHub의 Markdown을
내 Google Drive로.

GitHub Markdown Sync는 운영자가 선택한 GitHub 저장소의 .md 파일을 자신의 Google Drive 폴더로 복사하는 자동화입니다.

운영 주체는 Anarchists-Shoe-gazing입니다. 개인·운영자 용도로 사용하며, 공개 회원가입이나 제3자의 계정을 연결해 주는 서비스는 운영하지 않습니다.

어떻게 동작하나요?

선택한 GitHub 저장소 → 로컬 Mac mini 또는 GitHub Actions 실행 환경 → 기존 Google Drive 폴더

  • 저장소마다 지정된 Drive 폴더를 사용하고 원본의 하위 폴더 구조를 유지합니다.
  • 같은 경로의 파일은 업데이트할 수 있습니다. 원본에서 삭제된 파일을 Drive에서 자동으로 삭제하지 않습니다.
  • 자동 실행은 기본적으로 꺼져 있습니다. GitHub Actions 업로드는 GDRIVE_SYNC_ENABLED가 true인 저장소에서만 시작합니다.
Google 연결 전에 권한 범위를 확인하세요.

이 앱은 https://www.googleapis.com/auth/drive 권한을 사용합니다. 이 권한은 Google Drive 전체의 파일을 조회·생성·수정·삭제할 수 있는 범위입니다. 설정된 루트 폴더는 앱의 실제 작업 위치를 제한하지만, OAuth 권한 자체를 해당 폴더로 좁히지는 않습니다.

데이터와 연결은 소유자가 관리합니다

파일은 선택한 Drive 폴더에 남습니다. 자동화를 중단하거나 Google 연결을 해제해도 이미 복사한 파일은 자동으로 지워지지 않습니다. 데이터 처리, 보관 및 연결 해제 방법은 개인정보처리방침에 설명되어 있습니다.
